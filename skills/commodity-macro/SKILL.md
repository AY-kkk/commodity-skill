# 宏观事件怎样传到具体商品

## I · 如何判断

先定研究时点和对象。消息公布改变的是相对于既有预期的部分，同一冲击对今天的金融定价与下季度的实物需求可能产生不同结果。分别写出资产传导和产业传导，观察一条路径解释不了的现象。用现货成交、库存、产量和利润检验品种端是否已经兑现，再比较品种间的差异。宏观敏感度排序与预期涨幅排序是两种不同的结论。

## A1 · 合成演练

假设专项债发行提速，已披露投向以存量债务置换为主，工地资金到位、成交和钢厂订单尚未改善。研究员可以确认融资进度变化，但新增用钢需求仍待验证。若资金随后流向新开工项目，先跟踪项目到款和施工采购，再看螺纹表需与社会库存。若连续两个周度观察窗口都缺少新增订单，撤回“实物需求即将兑现”的假设。两周为本例的事前观察窗口。面试口述可说“我会先核对债券投向。发行数据回答钱筹了多少，项目到款和工地采购回答钢材用量是否变化。如果新增订单迟迟没有改善，我就下调这条传导路径的权重。”

## A2 · 何时调用

用户问财政、信用、利率、美元、全球增长或能源冲击如何改变一个或多个商品的需求、成本或预期，或者要写宏观数据点评时使用。若已指定具体企业的外币收付及期限，交给外汇敞口研究。若主要交付是两个合约的价差核算，进入有色价差研究。若只是把已有文字缩短，直接编辑原稿。

## E · 执行

1. 登记事件、发布时间、数据所属期、上期及修订情况、预期来源、目标市场、品种与分析期限。缺共识时写“预期差未定”，可给条件情景。用户要当前点评时用发布机构原文和可追溯行情，标明截止时间。
2. 选择至多三个候选因子，按冲击幅度、意外程度、约束性与持续期说明排序。比较“新因素上升”与“旧因素自然衰减”两种解释。区分库存同比和绝对库存、存量和新增资金、名义和实际利率。
3. 为每个品种写出完整链条。例：资金利率变化 → 融资和汇率 → 进口成本或库存融资 → 加工利润及采购；财政投向变化 → 项目到款 → 工地采购 → 表需及库存。标出中间环节方向、传递时滞和阻断条件，如资金用于置换或供给同步扩张。
4. 比较至少一项独立产业证据，并标明来源和频率。需求驱动应核对订单、发运或终端提货，去库要检查产量和库存转移。宏观成立且实物同向可上调确信度；仅金融价格响应则保留为预期；若现货相反写出替代解释与下一验证点。没有行情序列时把价格是否已反映预期列为缺口。
5. 交付简短研究备忘录。第一句写对象、期限及条件结论。随后给出“品种｜主要驱动｜领先指标｜实物验证｜证伪条件｜复核日期”表。按证据强弱写出可解释的排序，缺少可比证据时列为并列或待定。面试模式交付约一分钟的“我的判断、传导到哪个环节、怎样发现我错了”。
6. 下一数据窗口回看：假设本身错误、兑现慢于预期、品种或合约选择不匹配，分别记录原预期、实际观察与修订理由。

## B · 适用边界

只有政策口号或单个超预期数据时，输出条件路径和需补的数据，不报确定涨跌。政策口径变动、同比基数异常或观测时点早于事件时，先调整比较口径。教学中的周期长度、仓位和经验触发值不作为用户账户配置参数。面试不得把讲师项目写成本人经历。
