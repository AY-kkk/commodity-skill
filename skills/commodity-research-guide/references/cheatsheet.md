# 决策规则速查 — 大宗商品研究实习手册

| 能力 | 一句话规则 |
|---|---|
| 商品宏观传导研究 | 给出传导方向、期限、产业验证、相反证据和跟踪窗口。 |
| 产业基差与期现研究 | 先确定地区、品级、合约和现货减期货口径，再计算锁价、基差敞口与费用。 |
| 大宗贸易风险审查 | 穿透资金、货物、单据和相关方，列证据缺口、责任人、停止及复核条件。 |
| 油脂产业链研究 | 分油种核对到港、开机、产出、需求替代与区域库存，交付可复算的变动归因。 |
| 天气冲击商品研究 | 定位产区与敏感期，区分预报与实况，解释冲击可能在哪个交付期得到验证。 |
| 外汇与产业敞口研究 | 明确报价方向、净现金流与期限，比较匹配工具并解释剩余敞口。 |
| 有色价差研究 | 固定价差方向、单位、时点与成本，用库存和基差交叉验证，列出交割限制。 |
| 商品基本面与多空观点 | 交付可复算的平衡表、估值和驱动证据、情景及复核日期。油脂专属周报由油脂研究主办。 |
| 仓单交割与期限结构 | 列近远月可用数量、持仓与仓单口径、月差、交割约束和规则生效日。 |
| 跨品种相对价值 | 统一产出投入单位和配比，用两腿同一情景检验加工、替代或需求分化。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
