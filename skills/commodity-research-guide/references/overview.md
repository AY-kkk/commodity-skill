# 研究员的第一步是确定交付物

拿到问题时先确认对象、时间、品种或合同、已有证据，以及对方要作出的判断。给导师的是可复算的研究记录，晨会需要把差异讲清楚，面试则需要让对方听出你如何处理缺失信息。

| 对方的问题 | 主入口 | 交接 |
|---|---|---|
| 海外利率变动，铜和豆油哪个更敏感？ | 商品宏观传导研究 | 列出金融与实物渠道，再按品种核对库存、基差或压榨数据 |
| 想知道进口棕榈油的国内库存会不会增加 | 油脂产业链研究 | 天气模块只提供供应修订的时间窗；汇率模块只提供成本假设 |
| 仓单不清楚，业务说已用期货对冲 | 大宗贸易风险审查 | 查货权、合同与资金流；价格保护的残差交给产业基差模块 |
| 临近交割，铜近月相对远月走强是缺货吗？ | 仓单交割与期限结构 | 向有色研究取品牌、地点、报价和运费，按合约复核可交割数量与补货时间 |
| 从伦铜进口到国内，扣成本后还有多少？ | 有色价差研究 | 对齐两地品级、报价单位、付款日汇率、交付月及税费 |
| 甲醇本月库存与原估计相差多少，能改变观点吗？ | 商品基本面与多空观点 | 复核开工、检修与下游消费，解释平衡表差额及可能反证 |
| 豆油相对豆粕为何转弱？ | 跨品种相对价值 | 向油脂研究取同周压榨、两类收率、提货与库存，观察联合产出及下游差异 |
| 一船塑料出口，想辨别汇率风险 | 外汇与产业敞口研究 | 合同、币种、收汇日和同币种付款交给外汇模块；履约缺口交回贸易风控 |

**多意图任务**按用户最终要求选一个主入口。第二个入口只接收必要字段并返回一项可验证的中间结果。任务仅涉及个人旅游天气或生活消费时，直接说明超出课程范围。

**一分钟表达**。先说哪项条件改变了判断；用一个有日期的数据或合成演算说明机制；指出最可能推翻判断的信号；收尾交代准备验证的材料。课程案例用“培训中讨论了……，我会这样复核”。只有用户确实完成的工作才写成个人经历。
