# 共用口径

| 术语 | 使用前核对 |
|---|---|
| 基差 | 现货价减对应期货价。同日、同地区、同品级、同合约，注明税口径。 |
| 月差 | 默认近月减远月。持有成本比较常用远月减近月，须先换号。 |
| 敞口 | 记录方向、币种、金额和到期日；可抵扣的项目须满足时间与确定性约束。 |
| 供需平衡 | 期末库存等于期初加供应减去向，区分国内生产、进口、出口、消费与区域调运。 |
| 预期差 | 指出原先预期及其证据，观察数据如何改变它；盘面已反映的幅度须另作验证。 |
| 仓单与社会库存 | 两者口径可能重叠。确认可交割数量、地点、品牌、仓单有效期与日期后再比较。 |
| 研究缺口 | 数据缺失、规则待核、来源相互冲突分别登记；引用课程数字时保留其日期和适用范围。 |
| 库存消费比 | 期末库存除以所选期间的用量，明确消费或总使用量，以及用计算库存还是调查库存。 |
| 加工价差 | 按同一单位产出或投入折算各腿价格，列出单耗、收率、副产品和未计费用。 |
| 仓单覆盖率 | 指定合约已确认可用仓单吨数除以同日单边持仓吨数；其倒数为持仓相对仓单的倍数。 |
